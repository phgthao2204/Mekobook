1. Xác thực & Phiên làm việc POST Lấy OAuth 2.0 Access Token (Client Credentials / Password) /o/oauth2/token
HEADER:
Content-Type: application/x-www-form-urlencoded
BODY (Form):
grant_type: client_credentials
client_id: mekobook-mobile-client
client_secret: mekobook-mobile-secret
URL:
http://localhost:8080/o/oauth2/token
 
{
  "access_token": "9a38f4bc89e71234567890abcdef...",
  "token_type": "Bearer",
  "expires_in": 3600,
  "scope": "everything.read everything.write"
}
access_token
- Kiểu: String (JWT)
- Mô tả: Mã Bearer gắn vào header Authorization: Bearer cho mọi API sau.
token_type
- Giá trị: Bearer
expires_in
- Giá trị: 3600s (1 giờ)
client_id / secret
- Định danh ứng dụng di động
